# Laboratório do sistema real (até 3 vezes por semana)

**Terça:** escolha uma funcionalidade autorizada e rastreie **tela → rota →
controller → regra de negócio → consulta**. Primeiro tente explicar sozinho.

**Quinta:** formule uma hipótese sobre a mesma funcionalidade e valide com
ferramentas de debug/log no ambiente autorizado. Observe o caminho real.

**Sábado (opcional):** refaça a explicação em um diagrama genérico ou crie um
exercício fictício equivalente no repositório pessoal.

## Molde seguro de anotação

- Funcionalidade **genérica** investigada:
- Hipótese de fluxo (sem identificadores internos):
- Evidência observada (sem prints privados, segredos, clientes ou código):
- Dúvida / princípio técnico reutilizável:

> Não copie código, estrutura interna de banco, chaves, endpoints privados,
> dados de produção, regras comerciais sigilosas ou material da empresa.
> Siga as políticas e permissões internas. O Git pessoal só recebe exemplos seus.
