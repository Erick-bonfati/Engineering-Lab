# Engineering Lab — 52 semanas de engenharia de software

> **Dia 0:** preparação em 08/11/2026. **Primeiro dia:** 09/11/2026, às 19h.

Este repositório guarda **evidências de aprendizagem**, não resumos intermináveis.
A planilha é o calendário; este repositório contém desafios, código, testes e notas.

## Comece aqui

1. Confira [`SETUP.md`](SETUP.md) e verifique Git, PHP, Composer, Docker e VS Code.
2. Abra **a pasta inteira** `engineering-lab` no VS Code (`File > Open Folder`).
3. Leia [`docs/ROTINA.md`](docs/ROTINA.md) e [`docs/diario/2026-11-09.md`](docs/diario/2026-11-09.md).
4. Em 09/11, resolva [`exercicios/semana-01/dia-01/DESAFIO.md`](exercicios/semana-01/dia-01/DESAFIO.md).
5. Registre o raciocínio em `.md`, comite e marque ☑ na planilha.

## Regra de ouro: IA depois da tentativa

**15–25 minutos sem IA** para raciocinar ou buscar nas documentações. Se travar, formule
uma hipótese e um experimento. Então peça à IA *dicas ou revisão*, sem solicitar
imediatamente a solução completa. Leia o diff, execute testes e explique o resultado.

## Entrega mínima de cada estudo

- Um exercício, experimento ou análise verificável.
- Um `.md` curto: **o que tentei, como validei, o que aprendi, próxima dúvida**.
- Um commit claro. Exemplo: `study(php): diagnostico de tipagem e desconto`.

**Sem dados da empresa:** nunca suba credenciais, código proprietário, log sensível,
dados de clientes ou prints privados. Trabalhe com exemplos fictícios e genéricos.
